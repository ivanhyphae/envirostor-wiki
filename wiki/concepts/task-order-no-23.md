## Task Order No 23

Task Order No 23 is a component of [[project-no-s9525-06-44]], the remediation case file for the [[caltrans-modesto-soil-stockpiles]] site in Stanislaus County, California. This task order is associated with the work performed by [[geocon-consultants]] and falls under the purview of the [[central-valley-rwqcb]] and the [[department-of-toxic-substances-control]] through an [[interagency-agreement]].

## Site record

The [[human-health-risk-assessment]] update dated March 2013, prepared by Geocon Consultants, references Task Order No. 23 in relation to specific sampling and analysis activities. The document notes that under Task Order No. 23, soil samples were collected and analyzed for various constituents.
