# ⚠️ Data Quality Note
> An earlier version of the contaminants primer contained numbers generated by the sage-wiki compilation tool that **do not appear anywhere in the underlying source documents**. The tool suffered a column-misalignment bug when parsing wide lab-result tables (18+ analyte columns): it repeatedly misattributed real **strontium** values to barium, invented an entire fictitious "total mercury contamination" narrative from the monitoring-well ID "MW-1," and fabricated soil figures (a "760 mg/kg lead hotspot," "cadmium at 7.4 mg/kg," a PAH-to-landfill disposal story, TPH concentrations at nonexistent borings) that do not trace to any real report.
>
> Every number in the current version was independently verified by reading the raw source tables in `wiki/pdf2md/` directly — not the compiled `wiki/concepts/*.md` articles, which still contain the fabricated figures as of this writing and should be treated with caution until corrected. See **Data Gaps and Caveats** at the end for the specific files affected.
